Latiprimere is a cross-platform printing library for .NET. It finds printers, reads what they can do, sends them PDFs or raw printer data, and follows each job until it finishes. It has no user interface, so it works in console apps, services, containers and web back ends.

## Run the examples

Every example in these pages is in [`samples/Latiprimere.Examples`](https://github.com/bananocraft-miner82/Latiprimere/tree/main/samples/Latiprimere.Examples) in the repository. It is built with every change, so the code here always matches the API. To run one, clone the repository and name the example:

```bash
dotnet run --project samples/Latiprimere.Examples -f net10.0 -- list
```

Run it with no name to see them all.
